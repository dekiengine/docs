패키지

각 패키지는 github.com/dekiengine 아래의 독립된 저장소입니다. DekiEditor --packages-add <id> <project> 또는 패키지 관리자로 설치합니다.

그래픽과 사운드

패키지 요약
deki-2d 2D 콘텐츠 컴포넌트: 스프라이트와 스프라이트 배치, 텍스트(BitmapFont + TTF 베이킹), 애니메이션, 그라데이션, 버튼, 스크롤, 클리핑, 롤러.
deki-3d 렌더 패스로 동작하는 소프트웨어 래스터화 3D: 메시, 원근 카메라, .obj와 glTF 임포트를 제공하며 2D와 하나의 프레임 버퍼를 공유합니다.
deki-rendering 핵심 렌더링 파이프라인: 카메라, 렌더 시스템, 표준 2D 렌더러, QuadBlit, 렌더 패스, 정렬.
deki-particles 모듈식 파티클 시스템: 점/원/사각형 방출 형태, 중력, 항력, 초기 속도, 그리고 수명/크기/색상/회전 모디파이어.
deki-tween 30가지 이상의 이징 함수를 갖춘 트윈. 인스펙터에서는 TweenComponent를, 코드에서는 TweenManager를 사용합니다.
deki-tiledmapeditor-integration Tiled Map Editor 통합. 프로젝트에 .tmj 파일을 넣으면 에디터가 스트리밍 가능한 바이너리 타일맵으로 베이크합니다.
deki-audio 오디오 재생 주변 장치. I²S로 연결하는 MAX98357 D급 앰프.

게임 로직

패키지 요약
deki-physics-2d 2D 물리: 강체, 상자·원·캡슐·다각형 콜라이더, 트리거, 레이캐스트, 경첩과 밧줄. 고정 스텝으로 돌기 때문에 게임은 어떤 프레임 레이트에서도 똑같이 움직입니다.
deki-fsm 비주얼 상태 머신. 캔버스 위의 상태, 그룹, 전이와 각 상태 안의 액션 흐름.
deki-input 입력 디스패치와 충돌 감지. 포인터 / 터치 / 키 이벤트를 관심 있는 컴포넌트에 전달하고, 아날로그 스틱이 가리키는 방향을 읽습니다.
deki-nodegraph 노드 그래프 캔버스: 에디터 창, 실행 취소, 도메인, 노드 등록을 제공하며, 노드가 무엇을 의미하는지는 정하지 않습니다.
deki-json 런타임에 JSON 파싱이 필요한 패키지를 위한 패키지. 임베디드에서는 ESP-IDF cJSON을 감싸고, 데스크톱에서는 동등한 구현을 사용합니다.

디바이스와 플랫폼

패키지 요약
deki-miyoo-boards Miyoo Mini를 빌드 대상으로 제공합니다. 빌드 패널에서 고르면 Build로 Miyoo 메뉴용 앱을 만들고, Install로 휴대기의 SD 카드에 넣습니다. 앱은 순정 펌웨어든 Onion OS든 Apps에 나타납니다.
deki-esp32-integration ESP32 플랫폼 HAL: ESP-IDF SDMMC를 통한 SD 카드, FATFS 파일 시스템, 시리얼 명령, 메모리 및 파일 시스템 설정.
deki-desktop-integration Desktop과 Web 대상: 게임을 Windows, Linux, macOS용 프로그램으로, 또는 Emscripten으로 브라우저에서 플레이하는 웹 페이지로 빌드합니다.
deki-sdl3-integration SDL3(3.2.8) 기반의 데스크톱 디스플레이, 입력, 파일 시스템.
deki-tactility-integration Deki 게임을 장치 전체를 차지하는 펌웨어가 아니라, ESP32 보드용 운영체제인 Tactility 안의 앱으로 실행합니다.
deki-display Deki 자체 디스플레이 라이브러리. 취미용 보드에서 흔히 쓰는 화면을 구동하고, 터치를 읽고, 모든 프레임을 온전히 보냅니다.
deki-lovyangfx-integration LovyanGFX 1.2.19를 통한 임베디드 디스플레이와 터치. 일반적인 SPI/병렬 TFT와 FT6336U 정전식 터치 패널을 구동합니다.

핀과 버스

패키지 요약
deki-gpio 디지털 핀: 핀 출력, 핀 읽기, 핀 펄스 카운트. 그리고 보드의 주변 장치에 전원을 넣는 부트 단계.
deki-i2c I²C 버스 지원. 보드에서 버스를 한 번 설정하면 주변 장치 패키지(RTC, IMU, 터치)가 이를 공유합니다.
deki-i2s MAX98357 D급 앰프 같은 디지털 오디오 주변 장치를 위한 I²S 버스 지원.
deki-spi SPI 버스와 그 위의 장치. 부팅 단계에서 버스를 한 번 시작하면 디스플레이, SD 카드, 무선 장치가 이를 공유합니다.
deki-uart GPS 수신기 같은 시리얼 주변 장치를 위한 UART 지원.

센서와 저장소

패키지 요약
deki-gps GPS 주변 장치. 어떤 토커든 UART로 NMEA를 읽고, 수신기의 속도를 스스로 찾으며, 위성과 고도를 보고합니다.
deki-imu 하드웨어 만보계를 갖춘 6축 IMU(가속도계 + 자이로스코프). I²C로 연결하는 LSM6DS3.
deki-rtc 실시간 시계 주변 장치. 씬 컴포넌트에서 현재 시각을 읽고 쓰며, DS3231(I²C) 백엔드를 제공합니다.
deki-sdcard SD 카드 지원. 카드를 마운트해 에셋 매니저가 런타임에 카드에서 스트리밍할 수 있게 합니다.

네트워크와 무선

패키지 요약
deki-wifi Wi-Fi 추상화. 연결, 연결 해제, 상태 보고를 제공하며, 실제 백엔드는 플랫폼 통합 패키지가 제공합니다.
deki-ble Bluetooth Low Energy 추상화. BLE 페리페럴과 센트럴을 위한 엔진 측 인터페이스.
deki-http HTTP 클라이언트. 데스크톱에서는 WinHTTP 기반의 동기식 GET을 제공합니다. 임베디드 보드는 자체 네트워크 스택을 사용합니다.
deki-lora LoRa 무선. 패킷을 송수신하는 Semtech SX1262 드라이버로, 듀티 사이클 제한이 내장되어 있습니다.

기타

패키지 요약
deki-anbernic-boards Anbernic RG40XX H를 빌드 대상으로 제공합니다. 빌드 패널에서 고르면 Build로 휴대기의 순정 펌웨어용 앱을 만들고, Install로 SD 카드에 넣거나 Wi-Fi로 보냅니다. 앱은 Apps 목록에 나타납니다.
