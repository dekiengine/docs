Deki

임베디드 디스플레이와 데스크톱을 위한, 비주얼 에디터를 갖춘 모듈식 C++ 2D 엔진입니다.

여기에는 엔진 코어와 그 C++ API가 있습니다. 패키지 문서는 각 패키지에 있으며 아래에 링크가 있습니다. 모든 내용은 코드에서 생성됩니다(엔진 0.21.0).

  • 엔진 코어: 엔진 자체가 제공하는 컴포넌트와 설정
  • 프로젝트 설정: 모든 설정 섹션과 그것을 정의하는 곳
  • API 레퍼런스: 엔진과 에디터 DLL의 C++ 클래스(영어)
  • 에디터 저장소: 설정, 기여, 호환성 정책

패키지

각 패키지는 github.com/dekiengine 아래의 독립된 저장소입니다. DekiEditor --packages-add <id> <project> 또는 패키지 관리자로 설치합니다.

패키지 컴포넌트 요약
deki-2d 11 2D 콘텐츠 컴포넌트: 스프라이트, 텍스트(BitmapFont + TTF 베이킹), 애니메이션, 그라데이션, 버튼, 스크롤, 클리핑, 롤러.
deki-3d 2 렌더 패스로 동작하는 소프트웨어 래스터화 3D: 메시, 원근 카메라, .obj 임포트를 제공하며 2D와 하나의 프레임 버퍼를 공유합니다.
deki-audio 1 오디오 재생 주변 장치. I²S로 연결하는 MAX98357 D급 앰프.
deki-ble 0 Bluetooth Low Energy 추상화. BLE 페리페럴과 센트럴을 위한 엔진 측 인터페이스.
deki-desktop-integration 0 데스크톱 플랫폼 HAL: 데스크톱 빌드를 위한 메모리 및 파일 시스템 프로바이더.
deki-display 2 Deki 자체 디스플레이 라이브러리. 취미용 보드에서 흔히 쓰는 화면을 구동하고, 터치를 읽고, 모든 프레임을 온전히 보냅니다.
deki-esp32-integration 2 ESP32 플랫폼 HAL: ESP-IDF SDMMC를 통한 SD 카드, FATFS 파일 시스템, 시리얼 명령, 메모리 및 파일 시스템 설정.
deki-fsm 1 비주얼 상태 머신. 캔버스 위의 상태, 그룹, 전이와 각 상태 안의 액션 흐름.
deki-gpio 1 디지털 핀: 핀 출력, 핀 읽기, 핀 펄스 카운트. 그리고 보드의 주변 장치에 전원을 넣는 부트 단계.
deki-gps 2 GPS 주변 장치. 어떤 토커든 UART로 NMEA를 읽고, 수신기의 속도를 스스로 찾으며, 위성과 고도를 보고합니다.
deki-http 2 HTTP 클라이언트. 데스크톱에서는 WinHTTP 기반의 동기식 GET을 제공합니다. 임베디드 보드는 자체 네트워크 스택을 사용합니다.
deki-i2c 1 I²C 버스 지원. 보드에서 버스를 한 번 설정하면 주변 장치 패키지(RTC, IMU, 터치)가 이를 공유합니다.
deki-i2s 0 MAX98357 D급 앰프 같은 디지털 오디오 주변 장치를 위한 I²S 버스 지원.
deki-imu 1 하드웨어 만보계를 갖춘 6축 IMU(가속도계 + 자이로스코프). I²C로 연결하는 LSM6DS3.
deki-input 3 입력 디스패치와 충돌 감지. 포인터 / 터치 / 키 이벤트를 관심 있는 컴포넌트에 전달합니다.
deki-json 0 런타임에 JSON 파싱이 필요한 패키지를 위한 패키지. 임베디드에서는 ESP-IDF cJSON을 감싸고, 데스크톱에서는 동등한 구현을 사용합니다.
deki-lora 1 LoRa 무선. 패킷을 송수신하는 Semtech SX1262 드라이버로, 듀티 사이클 제한이 내장되어 있습니다.
deki-lovyangfx-integration 2 LovyanGFX 1.2.19를 통한 임베디드 디스플레이와 터치. 일반적인 SPI/병렬 TFT와 FT6336U 정전식 터치 패널을 구동합니다.
deki-nodegraph 0 노드 그래프 캔버스: 에디터 창, 실행 취소, 도메인, 노드 등록을 제공하며, 노드가 무엇을 의미하는지는 정하지 않습니다.
deki-particles 1 모듈식 파티클 시스템: 점/원/사각형 방출 형태, 중력, 항력, 초기 속도, 그리고 수명/크기/색상/회전 모디파이어.
deki-rendering 2 핵심 렌더링 파이프라인: 카메라, 렌더 시스템, 표준 2D 렌더러, QuadBlit, 렌더 패스, 정렬.
deki-rtc 2 실시간 시계 주변 장치. 씬 컴포넌트에서 현재 시각을 읽고 쓰며, DS3231(I²C) 백엔드를 제공합니다.
deki-sdcard 1 SD 카드 지원. 카드를 마운트해 에셋 매니저가 런타임에 카드에서 스트리밍할 수 있게 합니다.
deki-sdl3-integration 2 SDL3(3.2.8) 기반의 데스크톱 디스플레이, 입력, 파일 시스템.
deki-spi 1 SPI 버스와 그 위의 장치. 부팅 단계에서 버스를 한 번 시작하면 디스플레이, SD 카드, 무선 장치가 이를 공유합니다.
deki-tactility-integration 2 Deki 게임을 장치 전체를 차지하는 펌웨어가 아니라, ESP32 보드용 운영체제인 Tactility 안의 앱으로 실행합니다.
deki-tiledmapeditor-integration 3 Tiled Map Editor 통합. 프로젝트에 .tmj 파일을 넣으면 에디터가 스트리밍 가능한 바이너리 타일맵으로 베이크합니다.
deki-tween 1 30가지 이상의 이징 함수를 갖춘 트윈. 인스펙터에서는 TweenComponent를, 코드에서는 TweenManager를 사용합니다.
deki-uart 0 GPS 수신기 같은 시리얼 주변 장치를 위한 UART 지원.
deki-wifi 0 Wi-Fi 추상화. 연결, 연결 해제, 상태 보고를 제공하며, 실제 백엔드는 플랫폼 통합 패키지가 제공합니다.
