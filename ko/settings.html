프로젝트 설정

프로젝트의 settings/ 아래에 둘 수 있는 모든 설정 섹션과 그것을 정의하는 곳입니다. 파일의 키는 속성 이름입니다.

섹션 정의한 곳 속성 수
코어 engine 2
단위 engine 3
렌더링 deki-rendering 4

엔진 섹션

코어 설정

프로젝트 설정 섹션 Core(CoreProjectSettings)입니다.

카테고리: 설정 · 유형: Deki::CoreProjectSettings

속성 유형 기본값 제약 설명
capFps bool true 플레이 모드 FPS를 아래의 목표 프레임 레이트로 제한합니다. 끄면 게임이 에디터의 새로 고침 빈도(수직 동기화 시 보통 60 Hz)로 실행됩니다.
targetFps int32 60 1~240 제한이 켜져 있을 때의 목표 프레임 레이트(FPS)입니다. 게임은 이 속도를 목표로 하며, 하드웨어가 따라가지 못하면 더 느리게 실행됩니다. 'FPS 제한'이 꺼져 있으면 무시됩니다.

단위 설정

프로젝트 설정 섹션 Units(UnitProjectSettings)입니다.

카테고리: 설정 · 유형: Deki::UnitProjectSettings

속성 유형 기본값 제약 설명
inspectorUnit enum "Pixels" Pixels, Meters 인스펙터 표시 방식입니다. 픽셀: 물리량 필드를 px / px/s / px/s²로 표시합니다. 미터: 같은 필드를 m / m/s / m/s²로 표시합니다. 내부 저장은 어느 쪽이든 항상 미터입니다.
pixelsPerMeter float 16 1~1024 월드 스케일: 월드 공간 1미터를 프레임 버퍼 몇 픽셀로 렌더링할지 정합니다. 인스펙터의 px<->m 변환과 새 카메라의 기본 줌(CameraComponent::pixelsPerMeter 센티널 값)에 사용됩니다.
temperatureUnit enum "Celsius" Celsius, Fahrenheit 인스펙터에 표시할 온도 단위입니다. 저장은 항상 섭씨로 하며, 이 설정은 표시하고 입력하는 값만 바꿉니다.

패키지 섹션은 위에 링크된 각 패키지의 사이트에 설명되어 있습니다.
