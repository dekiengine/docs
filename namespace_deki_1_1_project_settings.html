◆ ReadPackageSettingBool()

bool Deki::ProjectSettings::ReadPackageSettingBool ( const char * section,
const char * key,
bool & out )

Reads one package setting from the last Load().

section is the DEKI_PROJECT_SETTINGS_SECTION name (such as "Rendering"), key the reflected field name. Works without the settings registry, which device builds lack; editor builds should read the registry instance instead. Returns false when no file is loaded, the section or key is missing, or the stored type is a different one.

◆ Write()

std::vector< uint8_t > Deki::ProjectSettings::Write ( Storage::Location assetStorage,
int32_t targetFPS = 0,
const char * startupScene = nullptr,
const char * rendererName = nullptr,
const char *const * passNames = nullptr,
int passCount = 0,
float screenDiagonalInches = 0.0f )

Builds a project_data.bin image (editor only).

targetFPS 0 means no limit; startupScene may be nullptr; screenDiagonalInches 0 means unknown. Returns the bytes, rather than filling a caller's buffer, because the packageSettings chunk grows with the settings registry and no caller can know the size. Empty only when nothing could be written.
