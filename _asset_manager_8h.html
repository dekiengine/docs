Detailed Description

Unified asset manager for loading assets by GUID or path.

Single AssetManager that works on all platforms:

  • Load<T>() - loads using path, looks up GUID from table
  • LoadByGuidAndType() - loads using GUID and type name string

The GUID table is loaded at startup from a file generated by the build system.
