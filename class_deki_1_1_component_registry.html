◆ GetMetaByFormerTypeId()

const ComponentMeta * Deki::ComponentRegistry::GetMetaByFormerTypeId ( uint32_t formerTypeId) const

Get metadata from the HASH of a name a component used to have.

The string form of a rename is handled by GetMeta(name), which falls back to DEKI_FORMER_NAME. But a scene also stores component identity as a bare number in places where no name is written: ObjectRef::componentTypeId and PropertyRef::componentTypeId. Those numbers are the hash of whatever the class was called when the file was saved, and a hash cannot be mapped back to its string, so the name fallback cannot reach them.

This is the numeric equivalent: it indexes HashString(formerName) so a stale id resolves to the class that now owns that name. Callers rewrite the reference to the current id, which migrates the file on its next save.

Parameters
formerTypeIdA type id read from a file, possibly pre-rename
Returns
Pointer to metadata, or nullptr if no component ever had that name
