◆ GetMetaByFormerTypeId()

const ComponentMeta * Deki::ComponentRegistry::GetMetaByFormerTypeId ( uint32_t formerTypeId) const

Metadata for a type id that is the hash of a name a component used to have, or nullptr when no component ever had that name.

Scenes store some component references as a bare type id with no name (ObjectRef::componentTypeId, PropertyRef::componentTypeId). That id is the hash of the class name at save time, and a hash cannot be turned back into a name, so GetMeta(name) cannot resolve it. This looks up HashString(formerName) instead. Callers rewrite the reference to the current id, so the file is migrated on its next save.
