Detailed Description

The base class of every component.

A component is any class deriving publicly from Component. Nothing else is declared: the reflection codegen finds the class by its base, its identity is its qualified name (see TypeId.h) and the per-class operations below run through the ComponentTypeInfo the engine attaches when the instance is created (AddComponent<T>, the scene loader, the factory).

A component with exported fields and no lifecycle methods is data. One that declares Awake(), Start() or Update() takes part in the lifecycle, and only a class that declares Update() is ticked: the codegen records that per class, so a data component costs nothing per frame.

Lifecycle order:

  1. InternalAwake (engine) - resolves AssetRefs and ObjectRefs
  2. Awake() - once, after the references are resolved
  3. Start() - once, before the first Update, after every Awake has run
  4. Update() - every frame
  5. Render (RendererComponent)
