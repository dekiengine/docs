Detailed Description

Main editor application singleton (facade).

Provides Unity-like static access for EditorWindow and CustomEditor implementations: auto& app = EditorApplication::Get(); const char* projectPath = app.GetProjectPath(); Deki::Object* selected = app.GetActiveObject();

The main editor (EditorApp) populates this facade via SetProjectPaths() and SetActiveObject(). Engine editors only need to call the getters.
