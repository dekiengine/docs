◆ Load()

template<typename T>
T * Deki::AssetManager::Load ( const char * path,
bool cache = false )

Loads the asset of type T at path, written without the "assets/" prefix and extension (such as "scenes/Demo").

Returns nullptr on failure. T is any type with a registered loader (Scene is built in; packages register theirs with RegisterLoader). The type is part of the lookup key, so assets of different types can share a path.

Cacheable types are loaded once and shared, and cache does nothing for them. Non-cacheable types (such as Scene) return a fresh instance on every call; with cache, the file's bytes stay in RAM so later loads skip the disk.

auto* scene = AssetManager::Get()->Load<Scene>("scenes/Demo"); // fresh from disk auto* scene = AssetManager::Get()->Load<Scene>("scenes/Demo", true); // fresh from cached bytes

Registers how to load assets of type typeName (must match T::kAssetTypeName).

unloader frees one (delete when null); memLoader, optional, loads from bytes in memory (pack files). A cacheable type is loaded once and shared; otherwise each load returns a fresh instance that the caller owns.

◆ HasLoader()

True when a loader is registered for typeName.

The editor treats any .asset whose "type" has a loader (and no texture compiler) as a generic data asset, like a ScriptableObject: its JSON compiles straight to a MessagePack cache with no per-type editor.

◆ DropCache()

void Deki::AssetManager::DropCache ( )

Forgets the cache without freeing the assets, which may still be in use; the next load reads a fresh copy from disk.

The editor calls it when play mode stops. Leaves the epoch alone, since existing AssetRef::ptr values still point at live memory.

◆ LoadAssetRoot()

bool Deki::AssetManager::LoadAssetRoot ( const char * root)

Uses a build's exported assets under root (Storage::AssetRoot): reads root/asset_table.bin and root/pack_index.bin and loads every asset from root.

The engine calls it at startup for internal storage; the package that mounts external storage calls it once the card is up. Returns false, with the reason logged, when the table cannot be read.

True once assets can be loaded: the cache directory is set (editor edit mode) or the binary lookup table is loaded (play mode, device).

AssetRef::Get() skips loading until then, such as while ImportAllAssets compiles scenes before the filesystem is up.

◆ LookupPath()

Full path (cache directory + entry) for a GUID, or "" when unknown.

The reference points into a reused buffer and is valid until the next LookupPath call; it avoids a string copy on every AssetRef resolution.
