Definition AssetPipeline.h:110

Lists the derived cache files of a source asset.

Some asset types make extra cache files (font baking writes one variant per size plus its atlases); the owning package names their GUIDs here so the orphan sweep keeps them.

Insert every derived GUID into outValidGuids. The pipeline already keeps the source asset's own GUID.

◆ MakeCacheStamp()

std::string DekiEditor::AssetPipeline::MakeCacheStamp ( const std::string & absolutePath) const

What a cache built from this source now would be built from: the size and modification time of the source and its .data file, and the cache format version; for a scene, also the registered component types and their properties.

Compared for equality (not "is the source newer"), so a file restored from a backup or unzip with an older time, or a cache format change, still counts as changed. Also used for the per-target export cache.
