Platform-specific delay (sleep) for the given number of milliseconds.

Used for frame rate limiting. Default is a no-op (busy wait falls through). Implementations:

  • SDL3: SDL_Delay()
  • ESP32: vTaskDelay(pdMS_TO_TICKS())
