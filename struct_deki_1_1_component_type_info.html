Detailed Description

Everything the engine knows about one component class.

One of these exists per reflected class, emitted by the reflection codegen into the owning package's generated sources and registered with ComponentFactory at startup. A component instance points at its class's entry (Component::GetTypeInfo), which is how GetType(), Deserialize() and the reference fixups work without the class declaring anything itself.

All strings are literals with static storage.
