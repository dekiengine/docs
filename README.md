# Deki documentation

Built output of the Deki documentation site, served by GitHub Pages at
https://dekiengine.github.io/docs/ — the component and package reference
generated from the engine's reflection metadata, plus the C++ API reference.

Nothing here is edited by hand. The pages are produced by
`tools/docs/build_docs.py` in the [deki-editor](https://github.com/dekiengine/deki-editor)
repository and pushed with `tools/docs/publish_docs.py`; fixes belong in the
source comments and package metadata there.

Engine, editor and packages: https://github.com/dekiengine
