Detailed Description

Camera interface for coordinate conversion.

Packages implement it on their camera components. The editor finds it with Object::FindInterface<ICamera>() without knowing the concrete type.

Coordinate model: screen pixels (float) = (world - camera) * pixelsPerMeter + buffer_center with world in meters. pixelsPerMeter is the buffer's height over the camera's ortho height (Deki::OrthoPixelsPerMeter, ScreenScale.h), so a camera shows the same height of world on every screen whatever its resolution; a wider screen shows more at the sides.
