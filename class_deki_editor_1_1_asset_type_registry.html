◆ Clear()

void DekiEditor::AssetTypeRegistry::Clear ( )

Drop every handler a package registered, keeping the editor's own (Scene, Asset).

Required before FreeLibrary on any package DLL: AssetTypeHandler holds std::functions built by package code, and a std::function points at its manager inside the DLL that created it, which runs on destruction as well as on copy. Handlers also capture the raw AssetTypeEditor* prototypes owned by AssetTypeEditorRegistry.

◆ ExtensionRevision()

uint32_t DekiEditor::AssetTypeRegistry::ExtensionRevision ( ) const
inline

Goes up each time a file extension becomes registered that was not a moment before: a package that loads after the project opened, or comes back after a reload (Clear), brings types whose files were skipped while it was away.

Registering a type again without a Clear in between leaves it as it was.
