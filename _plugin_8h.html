◆ DekiPluginSetImGuiContext()

DEKI_PLUGIN_API void DekiPluginSetImGuiContext ( void * context)

Receives the editor's ImGui context.

Only packages that call ImGui directly need it; packages that draw through deki-editor's EditorUI get the context through Deki::SetImGuiContext.

◆ DekiPluginGetImGuiContextSize()

DEKI_PLUGIN_API unsigned int DekiPluginGetImGuiContextSize ( void )

sizeof(ImGuiContext) as this package compiled it.

The loader refuses the package when it differs from its own, rather than let it corrupt the shared context. A package without it loads unchecked, so export it if you touch ImGui at all.

◆ DekiPluginClearRegistries()

DEKI_PLUGIN_API void DekiPluginClearRegistries ( void )

Removes everything this package registered in engine registries.

Called before the DLL is unloaded for a hot reload: anything holding a pointer into the DLL (factories, std::function callbacks, metadata) must go here, or it dangles once FreeLibrary runs.
