Detailed Description

Pictures the editor UI draws: the Scene and Play views, asset previews, font atlases.

Editor code and packages make them here: the editor draws with SDL's GPU API (Direct3D 12, Vulkan or Metal), which they never call.

A texture is a number, 0 for none. Its pixels are RGBA8 and start undefined; Update fills them from RGBA8 or RGB565. Draw one with ToImGui (ImGui::Image, ImDrawList::AddImage), or with AddImageNearest for sharp pixels when it is scaled up.
