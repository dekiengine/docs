Deki

A modular C++ 2D engine for embedded displays and desktop, with a visual editor. This reference is generated from the engine's own reflection metadata and headers (engine 1.3.0).

  • Packages: every package, its components and their properties
  • Engine core: components and settings the engine provides itself
  • Project settings: every settings section, by owner
  • API reference: the C++ classes of the engine and the editor DLL
