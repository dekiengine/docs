Deki

A modular C++ 2D engine for embedded displays and desktop, with a visual editor.

The engine core and its C++ API are here. Each package documents itself, linked below. All of it is generated from the code (engine 0.16.0).

  • Engine core: components and settings the engine provides itself
  • Project settings: every settings section, by owner
  • API reference: the C++ classes of the engine and the editor DLL
  • Editor repository: setup, contributing, compatibility policy

Packages

Each is its own repository under github.com/dekiengine. Install with DekiEditor --packages-add <id> <project>, or from the Package Manager.
