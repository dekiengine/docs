Detailed Description

Get the plugin name for display in the editor.

Returns
Human-readable name (e.g., "Pico SDK Builder")

What the plugin was compiled against.

A builder plugin shares C++ objects with the editor — PlatformConfig by reference, std::string and std::vector across the boundary, a vtable it inherits. That only works when both sides agree on the layout of those things, and when they disagree the failure is a corrupted field or a crash somewhere unrelated, not an error.

So the editor refuses to load a plugin that cannot prove it matches. This mirrors the reflection ABI guard the package loader already uses.

Read version THROUGH the pointer before copying the struct: if the plugin was built against a different revision, the struct it returns may be a different size, and copying it first is the bug PluginLoader documents.
