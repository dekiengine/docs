Detailed Description

Compile-time component identity derived from the class name.

A component's identity is its fully qualified C++ name ("Game::Health", "Deki::SetupComponent"). Nothing has to be declared for it: the compiler spells the name out in the signature of a function template, and that text is hashed at compile time. Scene files store the same name as text, so the on-disk key, the runtime id and the reflection codegen's view of a class all agree by construction.

The consequence to know about: renaming a class (or moving it to another namespace) changes its id. Scenes that reference the old name load it as a MissingComponent until the editor's redirect for that rename is in place.
