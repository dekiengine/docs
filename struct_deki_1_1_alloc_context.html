Detailed Description

Who asked for an allocation.

Filled in by the compiler.

Nobody writes one. Every allocating call takes an AllocContext whose default argument captures the call site, so an allocation is identified by where it was written: 

Deki::Memory::Allocate(n, Deki::Memory::Internal);
// -> 'void ParticlePool::SetCapacity(size_t)' at ParticlePool.h:47

There is no name to pass and no way to pass one. A hand-written tag is a second identity for the same allocation that has to be kept in step with the first, and the compiler already knows the answer.

Nothing is copied or allocated. Every member points at a string literal the compiler emitted with static storage duration, which is what makes it safe for the debug leak table to hold the pointer.
