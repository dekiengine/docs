Detailed Description

template<typename T>
class Deki::Buffer< T >

Owning array of T, freed when it goes out of scope.

Move-only, like every other owning handle: copying would need a second allocation that could fail, which a copy constructor cannot report.

T must be trivially copyable. Nothing here constructs or destroys elements; these are the raw pixel, glyph and sample buffers the engine passes to blitters and drivers, and Memory zeroes what it hands back.

(Re)allocate to count elements, returning whether it worked

The old contents are released first rather than copied: every caller here overwrites the buffer immediately afterwards, and copying would need both allocations live at once, which is the one thing a constrained part cannot spare. A count that has not changed is left alone, which is what makes this safe to call from a render path every frame.
