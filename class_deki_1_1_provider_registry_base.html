void Deki::ProviderRegistryBase::ClearPluginProviders ( )

Called by PackageLoader before FreeLibrary on each plugin DLL.

Removes every provider registered with isPlugin=true and frees the owned memory. Engine-core-owned providers (isPlugin=false) are preserved.
