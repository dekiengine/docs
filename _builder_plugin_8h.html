◆ kDekiBuilderAbiVersion

uint32_t kDekiBuilderAbiVersion = 2
constexpr

Bump when the builder interface changes shape: a new virtual, a reordered one, a changed signature, or a change to the layout of a struct that crosses the boundary.

2: Flash/SetTarget/GetSupportedTargets/SupportsFlash replaced by the deploy step; GetBootPayloadDirectory and DescribePlatform added; CMakeGen::PackageEntry carries framework dependencies as written; PlatformConfig loses its microcontroller fields (a backend reads those from frameworkOptions) and psramSize becomes externalMemorySize. The handshake also gained packageEntrySize, because ScanPackageManifests returns those by value: a backend built against another layout destroyed them with the wrong destructor and took the editor down with it.
