Detailed Description

Per-category provider registry that lives in deki-engine-core.dll.

One instance per category string (e.g. "location", "weather"). Package DLLs register their concrete providers here at DekiPlugin_RegisterComponents time.

The base stores IDekiPackage* pointers and is interface-agnostic on purpose: the typed wrapper (DekiProviderRegistry<Interface>) downcasts via static_cast. Safe because each (category, providerId) pair is owned by exactly one type.

Same DLL-boundary pattern as DekiSettingsRegistry — singleton symbol is exported from deki-engine-core.dll so every package DLL sees the same instance via dllimport. Plugin-aware ClearPlugin path lets PackageLoader drop providers before FreeLibrary without dangling vtables.
