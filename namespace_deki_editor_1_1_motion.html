Stored in the editor settings ("editor.reduceMotion"), read once and cached, so the check costs nothing per widget.

◆ To()

float DekiEditor::Motion::To ( ImGuiID id,
float target,
float seconds )

Move id's value linearly toward target so a full 0 -> 1 sweep takes seconds, and return it.

Time-based (the same length at 60 and 144 Hz). A value seen for the first time starts AT its target: a panel that just opened shows its state instead of animating everything in it from zero. Pair with an easing curve below for the shape.

◆ ItemHover()

float DekiEditor::Motion::ItemHover ( bool hovered)
inline

For a hand-drawn hover background, right after its item (usually an InvisibleButton): the fade for the item just submitted.

Draw the background while this is above 0, with its colour through WithAlpha, and it fades in and out instead of switching.

◆ ItemPress()

float DekiEditor::Motion::ItemPress ( )
inline

Press feedback for the same kind of item, also right after it: eased 0 -> 1 while it is held under the pointer, back to 0 after release.

Draw PressShade over the item's background at this value and it dips while pressed. (Native ImGui buttons get the same through PressMotion, with no call.)

float DekiEditor::Motion::RowHighlight ( ImGuiID id,
bool selected,
bool hovered,
float selectedAlpha,
float hoveredAlpha,
float * outSelected = nullptr )
inline

A row's highlight strength: the stronger of its selection fade (scaled by selectedAlpha) and its hover fade (by hoveredAlpha).

Draw the row as selected while this is above 0, with the highlight colour at this alpha as both its normal and hovered background. outSelected receives the eased selection fade alone, for anything else that marks selection.
